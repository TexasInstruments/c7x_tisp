    Nlms¶

    template<typename T>
    class Nlms : public TISP::VirtualOp¶

    Provides node-level APIs for the AUDIOLIB_nlms kernel from AUDIOLIB.

    This kernel implements the Normalized Least Mean Squares (NLMS) Adaptive Filter, which is used for adaptive filtering to estimate a clean signal from a noisy input. It adjusts the noisy input signal pIn to match the desired signal pInDesired by minimizing the error between the clean reference and the filtered output pOut.

    It supports both interleaved and non-interleaved formats of data.
