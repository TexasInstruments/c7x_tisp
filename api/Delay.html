    Delay¶

    template<typename T>
    class Delay : public TISP::VirtualOp¶

    Provides node-level APIs for the AUDIOLIB_delay kernel from AUDIOLIB.

    This kernel copies each channel from the input buffer pX (interleaved or non-interleaved) to the output buffer pY based on a given delay size.

    For each channel, delay size elements of zeros are stored in the output and then the corresponding input channel is stored in the output.

    Public Functions¶

    Delay(T *pX, T *pD, T *pS, T *pY, size_t width, size_t height, size_t widthD, size_t heightD, size_t inPitchBytes, size_t delayBytes, size_t outPitchBytes, size_t interleave, size_t mode, size_t delaySize, ErrorCtxt &errorCtx)¶

    Creates an AUDIOLIB_delay node.

    [TISP::Delay constructor]

    This constructor initializes a node for the AUDIOLIB_delay kernel.

    Parameters:¶
    *pX

    [in] : Pointer to the input matrix. Initializes _pX.

    *pD

    [in] : Pointer to the input delay matrix with shape as follows.

    • If mode = ‘0’:

      • Width = _delaySize; Height = _height.

    • If mode = ‘1’:

      • Width = (_delaySize + _width); Height = _height. Initializes _pD.

    *pS

    [in] : Pointer to the intermediate scratch memory with the same shape as the input matrix. initializes _pS.

    *pY

    [out] : Pointer to the output matrix. Initializes _pY.

    size_t width¶

    [in] : Width of input matrix.

    size_t height¶

    [in] : Height of input matrix.

    size_t widthD¶

    [in] : Width of delay matrix.

    size_t heightD¶

    [in] : Height of delay matrix.

    size_t inPitchBytes¶

    [in] : Pitch of input matrix in bytes.

    size_t outPitchBytes¶

    [in] : Pitch of output matrix in bytes.

    size_t delayBytes¶

    [in] : Pitch of delay matrix in bytes.

    size_t interleave¶

    [in] : Indicates whether the input matrix data is interleaved:

    • 0: Non-interleaved (Rows represent channels, columns represent samples).

    • 1: Interleaved (Rows represent samples, columns represent channels).

    size_t mode¶

    [in] : Indicates the type of delay.

    • 0: Linear delay.

    • 1: Circular delay.

    size_t delaySize¶

    [in] : Number of elements in delay matrix.

    ErrorCtxt &errorCtx¶

    [in] : Error context for reporting constructor errors
