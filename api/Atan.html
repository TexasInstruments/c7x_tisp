    Atan¶

    template<typename T>
    class Atan : public TISP::VirtualOp¶

    Provides node-level APIs for the MATHLIB_atan kernel from MATHLIB.

    This kernel computes elementwise arc-tangent of an input array pIn and writes the resulting values to an output array pOut.

    Template Parameters:¶
    typename T¶

    : Supports float.
