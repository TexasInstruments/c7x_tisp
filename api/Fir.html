    virtual bool setParams(uint16_t paramId, void *value, size_t size, ErrorCtxt &errorCtx) noexcept override¶

    Update runtime parameters with detailed error reporting.

    Updates the specified runtime parameter by ID with the data provided in the value buffer. The node strictly validates that the provided size argument matches or exceeds the expected byte size for the given parameter before mapping the state into the active node memory.

    Parameters:¶
    uint16_t paramId¶

    [in] : Parameter ID to update

    void *value¶

    [in] : Pointer to a buffer containing the new parameter value

    size_t size¶

    [in] : The size in bytes of the payload

    ErrorCtxt &errorCtx¶

    [inout] : Error context for reporting errors

    Return values:¶

    • true – : Parameters updated successfully

    • false – : Failed to update parameters

    virtual bool getParams(uint16_t paramId, void *value, size_t *size, ErrorCtxt &errorCtx) noexcept override¶

    Retrieve current runtime parameters with detailed error reporting.

    This API fetches the current live state from the node for the specified parameter ID and writes it into the provided buffer.

    If the user provides a buffer, it populates the requested data. If the buffer is too small (or value is nullptr), it safely fails (returns false) but injects the exact required byte capacity into *size, allowing the application to re-allocate precisely.

    Parameters:¶
    uint16_t paramId¶

    [in] : Parameter ID to query

    void *value¶

    [out] : Pointer to a buffer where parameters will be stored

    size_t *size¶

    [inout] : Input: Capacity of value buffer in bytes. Output: Actual bytes written or required.

    ErrorCtxt &errorCtx¶

    [inout] : Error context for reporting errors

    Return values:¶

    • true – : Parameters retrieved successfully

    • false – : Failed to retrieve parameters
