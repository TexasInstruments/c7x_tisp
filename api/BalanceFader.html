    BalanceFader¶

    template<typename T>
    class BalanceFader : public TISP::VirtualOp¶

    Provides node-level APIs for the AUDIOLIB_balanceFader kernel from AUDIOLIB.

    This kernel adjusts the sound distribution in an audio signal of the input buffer pX (interleaved or non-interleaved) by applying a corresponding gain factor and writes the resulting values to the output buffer pY.

    The gain factor for a channel is calculated based on given values of the following parameters:

    • balance,

    • fade,

    • array of channel config values,

    • lfeBalanceGainFactor,

    • lfeFaderGainFactor,

    • sideGainFactor,

    • lfeBalanceMode,

    • lfeFaderMode.

    Runtime Control Philosophy: The BalanceFader node supports dynamic parameter updates via a robust runtime API. Users can query or modify specific algorithmic parameters (such as balance, fade, LFE settings, and side gain) without needing to reconstruct the node.

    Template Parameters:¶
    typename T¶

    : Supports float.

    Parameters:¶
    *pX

    [in] : Pointer to the input matrix. Initializes _pX.

    *pG

    [in] : Pointer to the input gain values array. Initializes _pG.

    *pY

    [out] : Pointer to the output matrix. Initializes _pY.

    size_t widthIn¶

    [in] : Width of input matrix.

    size_t heightIn¶

    [in] : Height of input matrix.

    size_t gWidthIn¶

    [in] : Width of input gain matrix.

    size_t inPitchBytes¶

    [in] : Pitch of input matrix in bytes.

    size_t outPitchBytes¶

    [in] : Pitch of output matrix in bytes.

    size_t isInterleave¶

    [in] : Indicates whether the input matrix data is interleaved:

    • 0: Non-interleaved (Rows represent channels, columns represent samples).

    • 1: Interleaved (Rows represent samples, columns represent channels).

    float balance¶

    [in] : Left/Right control. Range: -1.0 (full left) to 1.0 (full right).

    float fade¶

    [in] : Front/Rear control. Range: -1.0 (full rear) to 1.0 (full front)

    int32_t *channelConfig¶

    [in] : Pointer to an integer array defining the speaker type for each channel.

    • ’0’: FRONT_LEFT.

    • ’1’: FRONT_LEFT_TREBBLE.

    • ’2’: FRONT_LEFT_MID.

    • ’3’: FRONT_LEFT_WOOFER.

    • ’4’: FRONT_RIGHT.

    • ’5’: FRONT_RIGHT_TREBBLE.

    • ’6’: FRONT_RIGHT_MID.

    • ’7’: FRONT_RIGHT_WOOFER.

    • ’8’: FRONT_CENTER.

    • ’9’: LOW_FREQUENCY_EFFECTS.

    • ’10’: SIDE_LEFT.

    • ’11’: SIDE_RIGHT.

    • ’12’: REAR_LEFT.

    • ’13’: REAR_RIGHT.

    • ’14’: TOP_FRONT_LEFT.

    • ’15’: TOP_FRONT_RIGHT.

    • ’16’: TOP_MIDDLE_LEFT.

    • ’17’: TOP_MIDDLE_RIGHT.

    • ’18’: TOP_REAR_LEFT.

    • ’19’: TOP_REAR_RIGHT.

    • ’20’: OVERHEAD.

    float lfeBalanceGainFactor¶

    [in] : LFE balance gain factor. Range: 0.0 (no effect) to 1.0 (full effect).

    float lfeFaderGainFactor¶

    [in] : LFE fader gain factor. Range: 0.0 (no effect) to 1.0 (full effect).

    float sideGainFactor¶

    [in] : Side gain factor. Range: 0.0 to 1.0.

    int32_t lfeBalanceMode¶

    [in] : The selected mode for how the LFE channel responds to the balance control.

    • ’0’: LFE_BALANCE_UNAFFECTED.

    • ’1’: LFE_BALANCE_PARTIAL.

    • ’2’: LFE_BALANCE_FULL.

    int32_t lfeFaderMode¶

    [in] : The selected mode for how the LFE channel responds to the fader control.

    • ’0’: LFE_FADER_UNAFFECTED.

    • ’1’: LFE_FADER_AVERAGE.

    • ’2’: LFE_FADER_POSITION_BASED.

    • ’3’: LFE_FADER_FULL.

    ErrorCtxt &errorCtx¶

    [in] : Error context for reporting constructor errors

    [inout] : Error context for reporting errors

    Return values:¶

    • true – : Parameters updated successfully

    • false – : Failed to update parameters

    virtual bool getParams(uint16_t paramId, void *value, size_t *size, ErrorCtxt &errorCtx) noexcept override¶

    Retrieve current runtime parameters with detailed error reporting.

    This API fetches the current live state from the node for the specified parameter ID and writes it into the provided buffer.

    If the user provides a buffer, it populates the requested data. If the buffer is too small (or value is nullptr), it safely fails (returns false) but injects the exact required byte capacity into *size, allowing the application to re-allocate precisely.

    Parameters:¶
    uint16_t paramId¶

    [in] : Parameter ID to query

    void *value¶

    [out] : Pointer to a buffer where parameters will be stored

    size_t *size¶

    [inout] : Input: Capacity of value buffer in bytes. Output: Actual bytes written or required.

    ErrorCtxt &errorCtx¶

    [inout] : Error context for reporting errors

    Return values:¶

    • true – : Parameters retrieved successfully

    • false – : Failed to retrieve parameters
