    Asrc¶

    template<typename T>
    class Asrc : public TISP::VirtualOp¶

    Provides node-level APIs for the AUDIOLIB_asrc kernel from AUDIOLIB.

    This kernel performs asynchronous sample rate conversion for input signals individually by converting audio data between different sample rates. It is optimized for high-performance, multi-channel audio processing.

    It supports both interleaved and non-interleaved formats of data.

    Example :

    | Input Sample Rate | Output Sample Rate | Input Sample Count | Input Channels | Output Sample Count | Output channels | |—————&#8212; |—————–&#8212;|—————–&#8212;|————-&#8212;|——————&#8212;|————–&#8212;| | 32000 | 32000 | 31 | 1 | 64 | 1 | | 32000 | 44100 | 256 | 1 | 385 | 1 | | 32000 | 48000 | 256 | 1 | 416 | 1 | | 44100 | 32000 | 64 | 1 | 79 | 1 | | 44100 | 44100 | 256 | 1 | 288 | 1 | | 44100 | 48000 | 256 | 1 | 311 | 1 | | 48000 | 32000 | 256 | 1 | 203 | 1 | | 48000 | 44100 | 256 | 1 | 268 | 1 | | 48000 | 48000 | 256 | 1 | 288 | 1 |

    Configuration & Parameters:

    Parameter

    Configuration Time

    Description

    mode, ratio

    Runtime

    Asrc operating mode and ratio. ONLY runtime changeable parameter.

    Runtime Control: The mode and asrcRatio are the only parameters that can be changed at runtime. To update them, use setParams() with the payload format specified below. Use getParams() to retrieve the current state.

    typename T¶

    : Supports float.

    Creates an AUDIOLIB_asrc node.

    This constructor initializes a node for the AUDIOLIB_asrc kernel.

    Parameters:¶
    *pX

    [in] : Pointer to the input matrix. Initializes _pX.

    *pNonInterleavedData

    [in] : Pointer to buffer holding the intermediate non interleaved data. Initializes _pNonInterleavedData.

    *pFiltCoeffs

    [in] : Pointer to buffer holding polyphase filter cefficients. Initializes _pFiltCoeffs.

    *pFilterRembuf

    [in] : Pointer to buffer holding the filter remaining buffer. Initializes _pFilterRembuf.

    *pY

    [out] : Pointer to the output matrix. Initializes _pY.

    size_t widthIn¶

    [in] : Width of input matrix.

    size_t heightIn¶

    [in] : Height of input matrix.

    size_t inPitchBytes¶

    [in] : Pitch of input matrix in bytes.

    size_t widthOut¶

    [in] : Width of output matrix.

    size_t heightOut¶

    [in] : Height of output matrix.

    size_t outPitchBytes¶

    [in] : Pitch of output matrix in bytes.

    size_t maxSampleCountPerBlock¶

    [in] : Max number of asrc input samples per data block.

    size_t outputSampleCount¶

    [in] : Number of output samples per data block.

    size_t sampleDataType¶

    [in] : Asrc input sample’s data type.

    size_t inputSampleRate¶

    [in] : Input sample rate. Allowed values are 32kHz, 44.1 kHz, and 48 kHz.

    size_t outputSampleRate¶

    [in] : Output sample rate. Allowed values are 48 kHz.

    size_t numChannels¶

    [in] : Number of asrc channels.

    size_t frameModuloFactor¶

    [in] : Frame modulo factor, used to calculate the output sample count. This is used to ensure that the output sample count is a multiple of this factor.

    size_t isInterleave¶

    [in] : Indicates whether the input matrix data is interleaved:

    • 0: Non-interleaved (Rows represent channels, columns represent samples).

    • 1: Interleaved (Rows represent samples, columns represent channels).

    ErrorCtxt &errorCtx¶

    [in] : Error context for reporting constructor errors

    virtual bool setParams(uint16_t paramId, void *value, size_t size, ErrorCtxt &errorCtx) noexcept override¶

    Update runtime parameters with detailed error reporting.

    Updates the specified runtime parameter by ID with the data provided in the value buffer. The node strictly validates that the provided size argument matches or exceeds the expected byte size for the given parameter before mapping the state into the active node memory.

    Parameters:¶
    uint16_t paramId¶

    [in] : Parameter ID to update

    void *value¶

    [in] : Pointer to a buffer containing the new parameter value

    size_t size¶

    [in] : The size in bytes of the payload

    ErrorCtxt &errorCtx¶

    [inout] : Error context for reporting errors

    Return values:¶

    • true – : Parameters updated successfully

    • false – : Failed to update parameters

    virtual bool getParams(uint16_t paramId, void *value, size_t *size, ErrorCtxt &errorCtx) noexcept override¶

    Retrieve current runtime parameters with detailed error reporting.

    This API fetches the current live state from the node for the specified parameter ID and writes it into the provided buffer.

    If the user provides a buffer, it populates the requested data. If the buffer is too small (or value is nullptr), it safely fails (returns false) but injects the exact required byte capacity into *size, allowing the application to re-allocate precisely.

    Parameters:¶
    uint16_t paramId¶

    [in] : Parameter ID to query

    void *value¶

    [out] : Pointer to a buffer where parameters will be stored

    size_t *size¶

    [inout] : Input: Capacity of value buffer in bytes. Output: Actual bytes written or required.

    ErrorCtxt &errorCtx¶

    [inout] : Error context for reporting errors

    Return values:¶

    • true – : Parameters retrieved successfully

    • false – : Failed to retrieve parameters
