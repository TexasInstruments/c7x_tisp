    group Supernodes

    SuperNode-level APIs.

    Unnamed Group¶

    static inline void graph(const SuperNode::superNodeVec &mySuperNodeVec)¶

    This function takes in alias of the superNodeVec (list of supernodes) and iterates through all the supernodes calling the exec function pertaining to that supernode.

    Parameters:¶
    &mySuperNodeVec

    [in] : Object to list of supernodes

    static inline void graph(SuperNode::superNodeVec *mySuperNodeVec)¶
    class BaseSuperNode¶
    #include <TISP_superNode.hpp>

    Provides the base class for Supernode. Contains member functions to create dma context and allocate memory required to store DRU-related parameters.

    Subclassed by TISP::SuperNode::I2dI2dToO2d< dTypeIn, dTypeOut >, TISP::SuperNode::I2dI2dToO2dO2d< dTypeIn, dTypeOut >, TISP::SuperNode::I2dToO2d< dTypeIn, dTypeOut >, TISP::SuperNode::I2dToO2dDiffDims< dTypeIn, dTypeOut >, TISP::SuperNode::I2dToO2dTranspose< dTypeIn, dTypeOut >, TISP::SuperNode::i2d_to_o2dMatMul< dTypeIn, dTypeOut >

    Public Functions¶

    virtual void exec() = 0¶

    This function is implemented by classes derived from TISP::SuperNode.

    virtual const opVec &getOpVec() const = 0¶

    This function returns a reference to the operator vector (opVec) contained within the supernode. This is used for profiling and other operations that need access to the individual nodes.

    Returns:¶

    Reference to the operator vector.

    virtual size_t getBlockCount() const = 0¶

    This function returns the block count for the supernode. This is used for profiling and other operations that need to know how many blocks were processed.

    Returns:¶

    The block count.

    void execDefault(std::unique_ptr<opVec> &myOpVec)¶

    This function executes a given supernode. It contains the boiler plate template for block-based DMA and compute flow. The function calls the execute::graph function which in turn executes the correct compute flow. For data movement, appropriate APIs are called around the execute::graph function. Typical execute case of most superNodes variants (derived classes)
