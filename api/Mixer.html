    Mixer¶

    template<typename T>
    class Mixer : public TISP::VirtualOp¶

    Provides node-level APIs for the TISP_mixer using AUDIOLIB_inputAggregator and DSPLIB_matMul kernels.

    The Mixer kernel aggregates multiple audio input buffers from different sources and applies coefficient-based mixing via matrix multiplication to produce mixed output channels.

    Processing Pipeline Overview: 

    ┌─────────────────────────────────────────────────────────────────────────────────────────┐
│                              MIXER KERNEL PROCESSING FLOW                               │
└─────────────────────────────────────────────────────────────────────────────────────────┘

   ┌─────────────────┐
   │  Input 0 (pX[0])│──┐     ┌──────────────────────────────┐
   │  [Ch0, Ch1]     │  │     │                              │
   └─────────────────┘  │     │   AUDIOLIB_inputAggregator   │     ┌─────────────────────┐
                        ├────►│                              │────►│   Scratch Buffer    │
   ┌─────────────────┐  │     │   Stacks all input channels  │     │   (pScratch)        │
   │  Input 1 (pX[1])│──┤     │   into a single contiguous   │     │   [TotalCh x N]     │
   │  [Ch2, Ch3]     │  │     │   planar buffer              │     │                     │
   └─────────────────┘  │     │                              │     │   ┌───────────────┐ │
                        │     └──────────────────────────────┘     │   │ Ch0: s0...sN-1│ │
   ┌─────────────────┐  │                                          │   │ Ch1: s0...sN-1│ │
   │  Input K (pX[K])│──┘                                          │   │ Ch2: s0...sN-1│ │
   │  [ChM-2, ChM-1] │                                             │   │ Ch3: s0...sN-1│ │
   └─────────────────┘                                             │   │     ...       │ │
                                                                   │   │ChM-1:s0...sN-1│ │
                                                                   │   └───────────────┘ │
                                                                   └──────────┬──────────┘
                                                                              │
                                                                              ▼
   ┌─────────────────────────────┐     ┌──────────────────────────────────────────────────┐
   │  Coefficient Matrix (pCoeff)│     │                                                  │
   │  [NumOutCh x TotalInCh]     │     │              DSPLIB_matMul                       │
   │                             │     │                                                  │
   │  ┌─────────────────────────┐│     │   Output = Coeff × Scratch                       │
   │  │ c00  c01  c02 ... c0M-1 ││     │   [NumOutCh x N] = [NumOutCh x M] × [M x N]      │
   │  │ c10  c11  c12 ... c1M-1 ││────►│                                                  │
   │  │ ...                     ││     │   Each output channel is a weighted sum of all   │
   │  │ cP-1,0 ... cP-1,M-1     ││     │   input channels based on coefficient row        │
   │  └─────────────────────────┘│     │                                                  │
   └─────────────────────────────┘     └──────────────────────────┬───────────────────────┘
                                                                  │
                                                                  ▼
                                       ┌──────────────────────────────────────────────────┐
                                       │              Output (Planar)                     │
                                       │              [NumOutCh x N]                      │
                                       │                                                  │
                                       │   ┌────────────────────────────────────────────┐ │
                                       │   │ OutCh0: w00*Ch0 + w01*Ch1 + ... + w0M*ChM-1│ │
                                       │   │ OutCh1: w10*Ch0 + w11*Ch1 + ... + w1M*ChM-1│ │
                                       │   │ ...                                        │ │
                                       │   │ OutChP-1: ...                              │ │
                                       │   └────────────────────────────────────────────┘ │
                                       └──────────────────────────┬───────────────────────┘
                                                                  │
                                                                  ▼
                                       ┌──────────────────────────────────────────────────┐
                                       │           (If isInterleave == 1)                 │
                                       │                                                  │
                                       │              DSPLIB_interleave                   │
                                       │                                                  │
                                       │   Converts planar [Channels x Samples] to        │
                                       │   interleaved [Samples x Channels] format        │
                                       └──────────────────────────┬───────────────────────┘
                                                                  │
                                                                  ▼
                                       ┌──────────────────────────────────────────────────┐
                                       │              Final Output (pY)                   │
                                       │   Format depends on isInterleave flag           │
                                       └──────────────────────────────────────────────────┘

    Key Dimensions:

    Parameter

    Description

    numInputs

    Number of input audio sources (K)

    heightScratch

    Total input channels across all inputs (M = sum of all Ch)

    widthCoeff

    Must equal heightScratch (total input channels M)

    heightCoeff

    Number of output channels (P)

    widthOut

    Number of samples per channel (N)

    heightOut

    Number of output channels (P)

    Mathematical Operation: 

    Y[p][n] = Σ (Coeff[p][m] × Scratch[m][n])  for m = 0 to M-1

Where:
  - p = output channel index (0 to P-1)
  - n = sample index (0 to N-1)
  - m = input channel index (0 to M-1)
  - M = total input channels (heightScratch)
  - P = output channels (heightCoeff)
  - N = samples per channel (widthOut)

    Creates an AUDIOLIB_mixer node.

    [TISP::Mixer constructor]

    This constructor initializes a node for the AUDIOLIB_mixer kernel that mixes multiple audio input sources into specified output channels using a coefficient matrix.

    Parameters:¶
    TISP_BufDesc2D *pX¶

    [in] : Pointer to array of input descriptors. Initializes _pX.

    size_t numInputs¶

    [in] : Number of input audio sources.

    T *pMixerCoeff¶

    [in] : Pointer to mixing coefficient matrix [heightCoeff x widthCoeff].

    size_t widthCoeff¶

    [in] : Width of coefficient matrix (total input channels).

    size_t heightCoeff¶

    [in] : Height of coefficient matrix (number of output channels).

    size_t strideCoeff¶

    [in] : Stride of coefficient matrix in bytes.

    T *pScratch¶

    [in] : Pointer to scratch buffer for intermediate aggregated data.

    size_t heightScratch¶

    [in] : Height of scratch buffer (total input channels).

    T *pOut¶

    [out] : Pointer to output buffer. Initializes _pY.

    size_t widthOut¶

    [in] : Width of output (number of samples).

    size_t heightOut¶

    [in] : Height of output (number of output channels).

    size_t strideOut¶

    [in] : Stride of output buffer in bytes.

    T *pOutTemp¶

    [in] : Pointer to temporary output buffer (for interleaved output).

    size_t widthOutTemp¶

    [in] : Width of temporary output.

    size_t heightOutTemp¶

    [in] : Height of temporary output.

    size_t strideOutTemp¶

    [in] : Stride of temporary output buffer in bytes.

    size_t isInterleave¶

    [in] : Data format flag:

    • 0: Planar (Channels x Samples).

    • 1: Interleaved (Samples x Channels).

    ErrorCtxt &errorCtx¶

    [in] : Error context for reporting constructor errors
