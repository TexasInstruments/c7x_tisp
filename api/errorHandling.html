    class GraphSetupErrorCtxt¶
    #include <TISP_ErrorCtxt.hpp>

    Error context for node and supernode creation.

    This class provides a mechanism for reporting and handling errors during the graph setup phase without using exceptions. It is designed to be used as an output parameter in constructors and factory methods.

    inline bool remapXLIBError(int statusCode, const char *functionName) noexcept¶

    Remaps standard library error codes (0-13) for AUDIOLIB, DSPLIB, MATHLIB.

    Centralizes error code mapping across all TISP libraries that share standard error codes. Performs semantic mapping where possible (e.g., NULL_POINTER → setNullPointerError) and falls back to generic library error reporting with the numeric status code.

    Maps codes used by: AUDIOLIB, DSPLIB, MATHLIB Code 0 = SUCCESS (no error set, returns true) Codes 1-12 = Various error conditions with semantic mapping Codes 13+ = Library-specific errors (generic library error with code)

    Example usage: 

    AUDIOLIB_STATUS ret = AUDIOLIB_gain_init(...);
if (!errorCtx.remapXLIBError(ret, "AUDIOLIB_gain_init")) {
    // Error handling
}

    Parameters:¶
    int statusCode¶

    The status code returned from an XLIB function (AUDIOLIB, DSPLIB, MATHLIB)

    const char *functionName¶

    The name of the XLIB function that failed (e.g., “AUDIOLIB_gain_init”)

    Returns:¶

    true if statusCode == 0 (SUCCESS), false otherwise
