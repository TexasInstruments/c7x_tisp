# Contributing to TISP

## Status

This repository is a **read-only public mirror**.
Community contributions are not accepted at this time.

Bug reports and feature requests are welcome via the
[TI E2E Community Forums](https://e2e.ti.com).

## Reporting Bugs

When filing a bug on E2E, include:

- **Device** — AM62Dx, AM275x, or J722S
- **Toolchain** — `ti-cgt-c7000` version
- **Node** — which `TISP::` node or namespace (e.g., `TISP::AUDIOLIB::GainNCh`)
- **Steps to reproduce** — minimal `create_graph()` / `execute_graph()` snippet
- **Expected vs actual output**
